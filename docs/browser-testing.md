# Browser smoke tests

Install the repository dependencies with `bun install --frozen-lockfile`, then install Chromium with `bunx playwright install chromium`. Run `npm run test:e2e:chromium` to build the production bundle, start Vite preview on `127.0.0.1:4173`, and exercise the import, settings, results, save/open, export, accessibility, mobile viewport, and async resource-import flows in Chromium. The full production Chromium suite passed 18/18 in this environment. It includes fresh-session timezone onboarding, the complete 2024 leap-year interval boundary, over-budget archive recovery, a maximum supported project save/open/recalculate round trip, exact measured solar interval import and export, and wind, generator, and mixed measured-resource journeys.

The Firefox project and `npm run test:e2e:firefox` command remain available, but Firefox automation has not completed successfully in the current environment; do not treat it as a verified browser. On 2026-10-13, the targeted fresh-session journey was attempted and stopped at browser launch because the Playwright Firefox 1555 executable was absent. No Firefox test code ran. Installing Playwright's matching Firefox build was previously attempted, but all Playwright CDN mirrors returned HTTP 403 (`Domain forbidden`). This is an environment download restriction, not a Firefox test result. Set `CHROMIUM_EXECUTABLE` if Chromium is installed outside Playwright's cache. The tests use actual rendered controls and do not mock simulation results.

The suite checks 320, 375, 390, and desktop-sized layouts for page-level horizontal overflow. Narrow data tables may scroll inside their own labelled wrappers. It checks accessible names for numeric controls in each battery and generation asset editor, announces invalid load CSV errors, exercises the dispatch table alternative from the keyboard, verifies visible focus, and checks the reduced-motion stylesheet.

`FIREFOX_EXECUTABLE` can select a compatible Playwright-controlled Firefox binary. A distro Firefox ESR package is not necessarily compatible with Playwright's automation protocol; prefer the matched build installed by `npx playwright install firefox`.

No lower-memory reference device was available during this run. A provisional target profile is a 4-core x86_64 laptop with 8 GiB RAM, testing current stable Chromium at 390 px and desktop viewport widths; it has not been measured. Current performance numbers describe only the managed runner in [the performance budget](performance-budget.md); they do not establish minimum-device requirements or support guidance. The maximum-project archive journey passed three isolated Chromium runs, but that fixture has solar and wind data attached with generation disabled. Active 35,136-interval mixed generation, Chromium process-tree memory, and interaction/cancellation responsiveness at that cadence remain unqualified.
